Console homebrew

Open-source tools for the GameCube, Wii, Dreamcast and PlayStation: boot discs that burn on a CD-R or DVD-R, and SD-card tools for making 1:1 backups of discs you own. No games: bring your own. A Wii only reads burned DVDs with a modchip, and only on the early drive models; DVD+R discs also need their book type set to DVD-ROM, which Krouton can do.

The Homebrew Channel (HackMii Installer)

Where Wii homebrew starts: it installs the Homebrew Channel and BootMii, from which CleanRip and USB Loader GX run. The installer is free but its authors only offer it from their own site.
